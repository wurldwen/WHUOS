# 时钟中断测试说明

## 测试目标

本测试分为两部分：
1. **时钟滴答测试**：观察时钟中断是否正常触发
2. **时钟快慢测试**：通过修改 INTERVAL 观察时钟滴答的快慢

## 测试实现

### 1. 时钟滴答测试

在 `kernel/trap/trap_kernel.c` 的 `timer_interrupt_handler()` 函数中：
- 每次时钟中断时输出字符 `T`
- 每个 `T` 代表一次时钟滴答（tick）

```c
// 1. 时钟滴答测试：输出"T"字符表示时钟滴答
printf("T");
```

**预期输出**：
```
TTTTTTTTT
ticks = 10
TTTTTTTTTT
ticks = 20
TTTTTTTTTT
ticks = 30
...
```

### 2. 时钟快慢测试

在 `timer_interrupt_handler()` 函数中：
- 每 10 次滴答输出一次 ticks 计数值
- 通过观察 ticks 增长速度判断时钟快慢

```c
// 2. 时钟快慢测试：每10次滴答输出一次ticks值
int ticks = timer_get_ticks();
if (ticks % 10 == 0) {
    printf("\nticks = %d\n", ticks);
}
```

## 修改 INTERVAL 测试不同速度

在 `include/dev/timer.h` 中修改 `INTERVAL` 宏定义：

```c
// 默认值（约 0.1 秒/次）
#define INTERVAL 1000000

// 慢速测试（约 1 秒/次）
#define INTERVAL 10000000

// 快速测试（约 0.01 秒/次）
#define INTERVAL 100000
```

### 测试步骤

1. **默认速度测试** (INTERVAL = 1000000)
   ```bash
   cd /home/hwt/桌面/sources/lab/OSLab/WHUOS/whu-oslab-lab3/code
   make clean && make && make qemu
   ```
   观察：大约每 0.1 秒输出一个 `T`，每秒输出 10 个 `T`

2. **慢速测试** (INTERVAL = 10000000)
   - 修改 `include/dev/timer.h` 中的 INTERVAL 为 10000000
   - 重新编译运行
   - 观察：大约每 1 秒输出一个 `T`

3. **快速测试** (INTERVAL = 100000)
   - 修改 `include/dev/timer.h` 中的 INTERVAL 为 100000
   - 重新编译运行
   - 观察：大约每 0.01 秒输出一个 `T`，`T` 字符快速滚动

## 验证要点

1. **时钟滴答是否正常**
   - `T` 字符应该持续、规律地输出
   - 不应该有长时间停顿

2. **ticks 计数是否正确**
   - ticks 值应该单调递增
   - 每次输出应该增加 10（因为每 10 次滴答输出一次）

3. **INTERVAL 修改是否生效**
   - 修改 INTERVAL 后，`T` 的输出速度应该明显改变
   - INTERVAL 越大，`T` 输出越慢
   - INTERVAL 越小，`T` 输出越快

## 退出 QEMU

按 `Ctrl+A`，然后按 `X` 退出 QEMU 模拟器

## 注意事项

1. 每次修改 INTERVAL 后需要重新编译：`make clean && make`
2. INTERVAL 不宜设置过小（< 10000），可能导致系统过于频繁响应中断
3. 多核系统下，每个核心都会触发时钟中断，可能看到多个 `T` 同时输出
